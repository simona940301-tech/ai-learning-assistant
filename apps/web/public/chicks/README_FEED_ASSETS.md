# 飼料相關資源檔案位置

## 📁 上傳位置

**目錄路徑：** `apps/web/public/chicks/`

## 📝 建議檔案名稱

1. **飼料碗圖示**（主要使用）：
   - `feed_bowl.png` 或 `feed_bowl.svg`
   - 建議尺寸：64x64px 或 128x128px

2. **飼料圖示**（可選）：
   - `feed.png` 或 `feed.svg`
   - 建議尺寸：32x32px 或 64x64px

## 🎨 設計建議

- 使用透明背景（PNG 格式）
- 顏色建議：金黃色、棕色系（符合飼料視覺）
- 風格：與現有小雞圖片風格一致（可愛、簡約）
- 圖示內容：可以是碗裝飼料、飼料顆粒、或飼料袋

## 📍 使用方式

上傳後，可在以下位置引用：

```typescript
// 在組件中使用
<Image src="/chicks/feed_bowl.png" alt="飼料碗" />
```
