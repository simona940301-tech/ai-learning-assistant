## 🐛 常見問題

### 問題 1: React Hooks 錯誤（已修復 ✅）

**錯誤訊息**: "Rendered more hooks than during the previous render"

**狀態**: ✅ 已修復（2025-12-01）

**原因**: `BackpackReader` 組件中有 hooks 被放在條件返回之後

**解決**: 已將所有 hooks 移到組件頂部，符合 React Hooks 規則

**影響**: 不影響 AI 優化驗證，但會阻止 Backpack 功能正常運作

### 問題 2: 請求失敗 (401/403)

**解決**:
- 確認已登入
- 檢查環境變數配置
- 確認 API Key 有效

### 問題 3: 串流中斷

**解決**:
- 檢查網路連線
- 確認 Gemini API Key 有效
- 查看伺服器日誌

### 問題 4: 響應時間過長

**解決**:
- 檢查 Gemini API 狀態
- 確認環境變數配置
- 查看伺服器資源使用

### 問題 5: RAG 性能不達標

**解決**:
- 檢查 Redis 快取是否連接
- 驗證檔案大小（建議 < 10MB）
- 查看 Console 日誌中的性能指標
- 確認網路連線穩定性
