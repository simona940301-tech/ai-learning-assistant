# Game Status Bar 設計提案

## 📋 問題診斷

### 當前狀況
1. **組件已存在**：`GameStatusBar` 組件在 play 頁面中使用（第 592 行）
2. **數據依賴**：依賴 `progression` 和 `userStatus` 從 `usePlay()` hook
3. **顯示問題**：如果數據未加載，會顯示簡陋的加載狀態
4. **設計風格**：當前是像素風格，不符合 Candy Crush 風格要求

### 核心需求
- ✅ 類似 Candy Crush 的視覺風格
- ✅ 羽毛形式展示能量
- ✅ 頂級 UI 設計
- ✅ 最小化使用者認知負荷

---

## 🎨 設計方案

### 方案一：經典 Candy Crush 風格（推薦）

#### 設計特點
- **頂部固定欄位**：類似 Candy Crush 的頂部狀態欄
- **羽毛圖標陣列**：8 個羽毛圖標，已使用/未使用有視覺區分
- **圓潤卡片設計**：柔和的圓角、漸層背景、微光效果
- **清晰層次**：重要資訊（羽毛）突出，次要資訊（等級、金幣）輔助

#### 視覺結構
```
┌─────────────────────────────────────────┐
│  [Lv 5]  [████████░░]  [8/8 羽毛]  [💰1000]  [🔥3天] │
│          進度條         ⏱️ 30:00                      │
└─────────────────────────────────────────┘
```

#### 實現思路
1. **羽毛顯示**：8 個羽毛圖標橫向排列，已使用為灰色/半透明，未使用為彩色
2. **進度條**：圓潤的漸層進度條，帶有光澤效果
3. **倒數計時**：羽毛下方顯示恢復倒數，滿時顯示 "Full"
4. **卡片容器**：使用 `backdrop-blur` 和漸層背景，類似 Candy Crush 的玻璃質感

#### 優點
- ✅ 符合 Candy Crush 經典風格，使用者熟悉度高
- ✅ 視覺層次清晰，認知負荷低
- ✅ 羽毛狀態一目了然（8 個圖標）
- ✅ 實現相對簡單，使用現有組件庫

#### 缺點
- ⚠️ 在手機上可能佔用較多垂直空間
- ⚠️ 需要確保 8 個羽毛圖標在小螢幕上清晰可見

---

### 方案二：極簡卡片式（現代化）

#### 設計特點
- **單一卡片容器**：所有資訊整合在一個圓潤卡片中
- **羽毛進度條**：羽毛圖標嵌入進度條中，類似生命值條
- **資訊分組**：左側（等級、進度），中間（羽毛），右側（金幣、連擊）
- **動態效果**：羽毛恢復時有脈衝動畫

#### 視覺結構
```
┌─────────────────────────────────────────────┐
│  Lv 5  [████████░░]   🪶🪶🪶🪶🪶🪶🪶🪶   💰1000  🔥3天 │
│        XP 進度        8/8 Full              │
└─────────────────────────────────────────────┘
```

#### 實現思路
1. **羽毛進度條**：8 個羽毛圖標作為進度條的「節點」，已使用/未使用有顏色區分
2. **緊湊佈局**：所有資訊在一行顯示，減少垂直空間
3. **懸浮效果**：卡片有輕微陰影和 hover 效果
4. **響應式**：小螢幕上自動調整字體大小和間距

#### 優點
- ✅ 節省垂直空間，適合手機螢幕
- ✅ 現代化設計，符合當前 UI 趨勢
- ✅ 資訊密度高，一目了然
- ✅ 動畫效果可以增強互動感

#### 缺點
- ⚠️ 資訊密度高可能造成認知負荷
- ⚠️ 小螢幕上可能文字過小
- ⚠️ 需要精心設計響應式斷點

---

### 方案三：分層卡片式（遊戲化）

#### 設計特點
- **分層設計**：主要資訊（羽毛）獨立卡片，次要資訊（等級、金幣）在下方
- **羽毛展示區**：大尺寸羽毛圖標，帶有動畫效果
- **進度環形圖**：等級進度使用環形進度條（類似 Candy Crush 的目標進度）
- **互動反饋**：點擊羽毛可查看詳細資訊

#### 視覺結構
```
┌─────────────────────────────────┐
│  🪶🪶🪶🪶🪶🪶🪶🪶  8/8 Full  ⏱️ 30:00 │
│  羽毛能量                        │
└─────────────────────────────────┘
┌─────────────────────────────────┐
│  Lv 5  [████████░░]  💰1000  🔥3天 │
└─────────────────────────────────┘
```

#### 實現思路
1. **雙層卡片**：上層專注羽毛，下層顯示其他資訊
2. **大尺寸羽毛**：羽毛圖標放大，更容易識別
3. **環形進度**：等級進度使用 SVG 環形進度條
4. **展開/收起**：點擊可展開查看詳細資訊

#### 優點
- ✅ 羽毛資訊最突出，符合遊戲化需求
- ✅ 分層設計降低認知負荷
- ✅ 可擴展性高，未來可加入更多資訊
- ✅ 視覺吸引力強，適合遊戲場景

#### 缺點
- ⚠️ 佔用更多垂直空間
- ⚠️ 實現複雜度較高
- ⚠️ 需要處理展開/收起的動畫邏輯

---

## 🎯 推薦方案：方案一（經典 Candy Crush 風格）

### 推薦理由
1. **認知負荷最低**：使用者對 Candy Crush 風格熟悉，學習成本低
2. **視覺清晰**：8 個羽毛圖標直觀展示能量狀態
3. **實現簡單**：使用現有設計系統，開發效率高
4. **擴展性好**：未來可輕鬆加入新功能

### 設計細節

#### 顏色方案
- **背景**：`bg-gradient-to-r from-white/90 to-white/80 backdrop-blur-xl`
- **羽毛（已使用）**：`opacity-30 grayscale`
- **羽毛（未使用）**：`opacity-100` 彩色
- **進度條**：`bg-gradient-to-r from-emerald-400 to-emerald-600`
- **文字**：`text-foreground` 深色模式適配

#### 動畫效果
- **羽毛恢復**：脈衝動畫（`animate-pulse`）
- **進度條**：平滑過渡（`transition-all duration-300`）
- **倒數計時**：數字更新時輕微縮放

#### 響應式設計
- **桌面**：完整顯示所有資訊
- **平板**：調整間距，保持完整資訊
- **手機**：自動換行或縮小字體
