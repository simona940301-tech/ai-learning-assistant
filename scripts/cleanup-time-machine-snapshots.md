# 🧹 Time Machine 快照清理指南

## 问题说明

你看到的快照是**系统更新快照**（`com.apple.os.update-*`），这些快照通常被系统保护，无法直接删除。

## 🔍 当前快照状态

你的系统有以下快照：
- `com.apple.os.update-8580EF41777A373CFDD2481F6D7C5DABE2C62A48B3932EF124CDE166CC64CFD9`
- `com.apple.os.update-8CB4C3E94741BEAF5DD13C7D5256F45AB04DBB767F5B79B4D12DE5EE821580864F12DBF0DE375EA847829A297CE5976D`
- `com.apple.os.update-MSUPrepareUpdate`

这些是 macOS 系统更新时创建的本地快照，用于在更新失败时恢复系统。

## ✅ 解决方案

### 方法 1: 等待系统自动清理（推荐）

系统更新完成后，这些快照通常会在几天内自动删除。你可以：

1. **等待 3-7 天**：系统会自动清理这些快照
2. **完成系统更新**：如果还有未完成的更新，完成更新后快照会被删除

### 方法 2: 通过系统设置清理

1. 打开 **系统设置** > **通用** > **存储空间**
2. 点击 **推荐** 或 **存储建议**
3. 查看是否有 "Time Machine 快照" 选项
4. 如果有，点击清理

### 方法 3: 重启 Mac

有时重启后，系统会释放被占用的快照：

```bash
# 重启 Mac（在终端中）
sudo reboot
```

### 方法 4: 禁用 Time Machine 本地快照（谨慎使用）

如果你不使用 Time Machine，可以禁用本地快照：

```bash
# 禁用本地快照
sudo tmutil disablelocal

# 然后尝试删除快照
sudo tmutil deletelocalsnapshots /
```

**⚠️ 注意**：禁用本地快照后，如果系统更新失败，你将无法恢复到更新前的状态。

### 方法 5: 使用第三方工具

可以使用专业的清理工具：
- **CleanMyMac X**：可以安全清理系统快照
- **DaisyDisk**：可视化查看和清理大文件
- **OmniDiskSweeper**：查找占用空间的文件
